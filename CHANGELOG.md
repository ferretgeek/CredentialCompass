# Changelog

All notable changes to this project are documented here.

## [1.0.1] - 2026-08-09

- Reissued the public history after an adversarial two-engine secret scan found credential-shaped test identifiers; no real credential or personal data was present.
- Renamed the synthetic test fixture, retired the immutable `v1.0.0` tag, and republished from a history that scans clean across every reachable commit and tag.
- Includes the dependency, path-boundary, UI, documentation, and CodeQL hardening completed after the first public build.

## [1.0.0] - 2026-08-09

- First public release.
- Privacy-first CLIProxyAPI credential inventory with masked identities and opaque handles.
- Optional, disabled-by-default compatibility probe for classified health and quota signals.
- Reversible, opt-in status controls with exact confirmation phrases.
- Four persistent global themes, responsive interface, and SVG/PNG/ICO favicons.
- Loopback-first local service, hardened Docker deployment, bilingual documentation, tests, CI, CodeQL, and release privacy gates.
- Docker runtime updated to Python 3.14 after the Dependabot change passed all CI and CodeQL checks.
