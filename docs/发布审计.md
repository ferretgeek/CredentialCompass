## 结论

- 56 项单元与安全测试、Ruff、Bandit、pip-audit、构建与安装门禁通过。
- 桌面与 390×844 移动视口已实际检查；四套全局主题、深灰 `#17191d`、访问门禁与隐私遮罩工作正常。
- SVG、PNG、ICO 收藏图标、1280×720 实际界面图和 1280×640 社交封面均已核验。
- Gitleaks 与 TruffleHog 对公开新鲜克隆的完整历史及全部标签均为 0；自定义身份/地址检查和图片元数据检查无未解释结果。
- CodeQL、CI、Dependabot、Secret Protection、Push Protection 与私密漏洞报告均纳入在线门禁。

## 历史清理

最终对抗式复扫发现一个测试函数名恰好符合第三方 Lob 测试密钥的长度与前缀。它不是凭据，也不含个人信息；为避免外部扫描者得到误导性“已验证”结果，所有可达提交已重写。GitHub 的不可变 `v1.0.0` 标签按官方规则永久退役，干净发布线从 `v1.0.1` 继续。

旧历史只保存在工作区私有回滚 bundle 中，位于 `资料/安全修复备份/`，不得公开。GitHub 对不可变发布保留的证明与缓存不受普通 Git 重写控制，因此不能声称旧 SHA 已从互联网物理抹除；公开分支、标签与普通全量克隆不再引用它。
