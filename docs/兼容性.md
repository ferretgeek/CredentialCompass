# 兼容性说明

凭证罗盘面向由 CLIProxyAPI 管理的 Codex 凭证池，但它既不是 OpenAI 官方产品，也不是 Codex 登录工具。

## 两层能力

- **清单层（默认）**：读取 CLIProxyAPI 的凭证清单与启用状态，只形成遮罩账号和匿名句柄。
- **探测层（可选）**：通过 CLIProxyAPI 管理端的 `api-call` 能力，请求一个固定的 ChatGPT 使用量接口，再把响应缩减为健康和额度轮廓。

探测层依赖未作为稳定公共 API 承诺的兼容路径，可能随上游变化而失效，因此 `COMPASS_ENABLE_LIVE_PROBE=false` 是默认值。探测关闭时，凭证罗盘仍可安全完成清单盘点。

状态停用/恢复同样依赖 CLIProxyAPI 管理接口，并由 `COMPASS_ALLOW_STATUS_CHANGES=false` 默认关闭。升级 CLIProxyAPI 后，应先在隔离的合成或低风险账户上验证清单、探测与状态变更，再投入正式使用。

Codex 自身支持 ChatGPT 登录与 API Key 两类官方认证方式；请按 [OpenAI 官方 Codex 认证文档](https://learn.chatgpt.com/docs/auth)完成认证。不要把 OpenAI API Key、ChatGPT Cookie 或登录 Token 提交给凭证罗盘。

## 已验证运行环境

- Python 3.10–3.14
- Chromium 系浏览器、现代 Firefox 与 Safari 的当前版本
- CLIProxyAPI 管理端点可由凭证罗盘服务进程访问

由于 CLIProxyAPI 与兼容探测接口会演进，具体版本应以 CI、发布说明和部署者的隔离验证为准。
